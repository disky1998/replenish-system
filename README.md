# 智能补货辅助系统 v4.2.1

跨境电商亚马逊智能补货辅助系统（单文件离线/在线双模架构）。

## 🌟 核心功能特性
1. **多店铺同 ASIN 智能聚合**：自动合并同一国家多店铺的数据，自动提取与顺延有效售价；
2. **多仓成本智能路由**：根据 MSKU 及仓库优先级智能匹配对应仓库成本（支持深圳仓保底与亏本预警）；
3. **极速 120 FPS 趋势图**：
   - **多周期聚合表**：3 阶段独立时序解耦，7 天排在最左侧，顶端流线与微圆点自然呼应；
   - **30 天细分流水表**：全局单例高清交互浮窗，支持直接在单元格滑动实时查看单日销量；
4. **自动版本更新检测**：每次打开页面自动检测 GitHub 最新版，提供更新日志展示与一键免跳转下载新版本。
